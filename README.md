# DeutschLern — Web học tiếng Đức A1–C2

Web học tiếng Đức: trang giới thiệu → đăng ký / đăng nhập → menu đầy đủ bên trong.

- **Khóa học:** 18 bài theo chủ đề từ A1 đến C2
- **Từ vựng:** 164 từ có der/die/das, số nhiều, ví dụ, nghe phát âm
- **Flashcard** lật thẻ, **Ngữ pháp** 12 chủ điểm, **Hội thoại** 6 tình huống
- **Trắc nghiệm** 10 câu chấm điểm ngay, **Cá nhân** có điểm XP và 8 thành tích
- Tài khoản demo: `demo@deutschlern.vn` / `demo123` (hoặc vào bằng chế độ khách)

## Chạy web

Mở file `index.html` bằng trình duyệt là dùng được ngay (web tĩnh, không cần máy chủ).

> Lưu ý: bản này là web tĩnh nên tài khoản và tiến độ chỉ được lưu trên máy của từng người dùng (localStorage). Muốn tài khoản thật dùng chung cho mọi người trên nhiều máy thì cần thêm backend + cơ sở dữ liệu.
